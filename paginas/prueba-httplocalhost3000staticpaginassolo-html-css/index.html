Instrucciones Paso a Paso

Sigue estos pasos para probar la página web local y verificar su correcta carga

1

Inicia el Servidor Local

Asegúrate de que tu servidor local esté ejecutándose en el puerto 3000. Verifica que la URL localhost:3000 sea accesible desde tu navegador.

2

Accede a la Página

Navega a la dirección exacta: http://localhost:3000/static/paginas/solo-html-css-en/index.html en tu navegador principal.

3

Toma Screenshots

Captura imágenes de la página completa y de secciones específicas. Usa herramientas nativas del navegador o aplicaciones especializadas.

4

Verifica la Carga

Comprueba que todos los elementos se carguen correctamente: imágenes, estilos CSS, fuentes y cualquier recurso externo.

5

Prueba Responsive

Usa las herramientas de desarrollador del navegador para probar la página en diferentes tamaños de pantalla (móvil, tablet, escritorio).

6

Documenta Resultados

Registra cualquier problema encontrado: errores de carga, elementos rotos, problemas de diseño o de rendimiento.

Checklist de Verificación

Elementos clave a verificar durante la prueba de carga

La página carga completamente

Todos los recursos (HTML, CSS, imágenes) se descargan sin errores.

Los estilos CSS se aplican correctamente

La página mantiene su diseño visual sin elementos desalineados o sin estilo.

Las imágenes se muestran adecuadamente

Todas las imágenes aparecen en su tamaño y posición correctos, sin pixeleo.

Diseño responsive funcional

La página se adapta correctamente a diferentes tamaños de pantalla.

Sin errores en la consola

La consola de desarrollador no muestra errores JavaScript o de recursos.

Tiempo de carga aceptable

La página carga en menos de 3 segundos en conexiones promedio.
