Servicio API Integrado

Este sistema consume un backend RESTful en localhost:8000 con las siguientes rutas principales:

Endpoints Disponibles

GET
/api/mascotas

Obtiene lista de todas las mascotas registradas

POST
/api/mascotas

Registra una nueva mascota en el sistema

PUT
/api/mascotas/:id

Actualiza información de una mascota existente

DELETE
/api/mascotas/:id

Elimina una mascota del registro
