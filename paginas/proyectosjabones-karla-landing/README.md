# paginas/proyectosjabones-karla-landing

Generado para: Actúa como un Desarrollador Frontend Senior experto en React, Tailwind CSS y Shadcn/UI. Crea el proyecto en la carpeta proyectos/jabones-karla-landing. Necesito el código de una Landing Page moderna y minimalista para un emprendimiento de jabones artesanales. Requisitos Técnicos: Framework: Next.js (App Router) con TypeScript. Estilizado: Tailwind CSS. Componentes Shadcn/UI: Usa NavigationMenu, Card, Badge, Carousel y Button. Iconos: Lucide-react. Paleta de Colores de la Marca: Fondo de Página: #F5F1EB (Tono crema muy suave y orgánico). Color Principal de Acento: #8E44AD (El morado vibrante). Color Secundario de Acento: #2ECC71 (El verde menta suave). Color de Borde/Detalle: #D2B48C (Tono madera/crema oscuro). Color de Texto Principal: #4A3B2F (Marrón muy oscuro para legibilidad). Color de Fondo de Botones/Acciones: #A569BD (Una variante más suave del morado de acento). Estructura de la página (Single Page): Navbar: Logo centrado con efecto de desenfoque (glassmorphism) sobre #F5F1EB. Hero Section: Título elegante con tipografía Serif, subtítulo persuasivo y un botón CTA con el color principal morado. Sección Historia: Diseño de dos columnas (texto inspirador sobre procesos naturales + placeholder de imagen con bordes redondeados). Sección Modelos (Productos): Un grid de 3 cards modernas para los modelos principales de jabones. Cada card debe tener imagen, nombre, precio y un badge de Orgánico con el color secundario verde menta. Sección Aromas: Implementa un Carousel de Shadcn/UI que muestre diferentes aromas (Lavanda, Eucalipto, Cítricos, etc.) usando cards pequeñas y minimalistas con movimiento fluido. Sección Pagos y Social: Footer con iconos de métodos de pago (Visa, Mastercard, Transferencia) y enlaces a redes sociales (Instagram, Facebook, WhatsApp) usando iconos de Lucide. El diseño debe sentirse premium, limpio y transmitir calma, pero con toques de frescura vibrante.
